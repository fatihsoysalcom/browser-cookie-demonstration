# Browser Cookie Demonstration

This example demonstrates how a website can use browser cookies to track user consent for cookie usage. It shows a cookie banner that disappears once the user accepts, and how this acceptance is stored in a browser cookie.

## Language

`html`

## How to Run

Open the `index.html` file in your web browser.
